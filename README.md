### Simple Root Cause Data Analysis 
**Description:** The main goal of this side project is to practice root cause data analytics which is a problem-solving method used to identify the root cause of a metric shift. This project uses data from [this kaggle dataset](https://www.kaggle.com/datasets/ahmedmohamed2003/cafe-sales-dirty-data-for-cleaning-training/data). The dataset holds 10,000 rows about cafe sales to answer the goal of this project: "Why did Juice revenue drop 32% from January to July, then fully recover by October?" The project uses Excel for data quality checks and data cleaning and uses Pandas for the analysis.
